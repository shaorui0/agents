c0004 public-history-rewrite

What changed

  • History rebuilt locally. The pre-existing public content, with internal identifiers generalized, is one root commit; the 16 process commits of c0001-c0003 replay on top with identical content. All commits carry one author and committer email.
  • tools/check_rules.py: no legacy exemption. Every file is scanned; any hit fails.
  • README and docs/REQUIREMENTS.md (R8, D5, data boundary) now say the history was rebuilt and identifiers generalized.
  • Backup: local branch pre-public-history (never pushed). Rollback is git reset --hard pre-public-history.

Why

c0001 found internal identifiers in content that was already public and chose to report, not rewrite. A repo that teaches fail-closed and a data boundary should pass its own scan with no exemptions, and an exemption for “old files” is debt that never gets paid.

How the rewrite was done

  • Replacement is class-for-class and consistent: the same original maps to the same substitute everywhere, so cross-references in the prose still line up and meaning is unchanged. Cluster aliases become example prod aliases, cluster full names become generic region-style names (region facts in the prose are kept), ticket ids become TICKET-n, the workspace domain becomes a placeholder subdomain, home paths become ~/, the work-repo path and ops directory become placeholders.
  • A manual review beyond the pattern list found two more categories the patterns had missed (cloud cluster names, an ops-directory name). The pattern set was extended so the scan now covers them.
  • git rebase --onto replayed the 16 commits with no conflicts, then --reset-author per commit unified the identity.

Result

Before (extended patterns, backup branch): 49 hit lines in 13 files. After: 0, no exemptions. One author email across all commits. Tests green. Evidence lists categories and counts only.

Caveat

Hashes of c0001-c0003 changed, and this is local only. Until the rebuilt branch is pushed, the old history remains whatever was already published; replacing the public history is a force-push decision left to the owner.
